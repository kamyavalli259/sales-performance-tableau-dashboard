# Sales Performance and Profitability Dashboard

## Project Overview
Developed an interactive Tableau dashboard using the Superstore dataset to analyze sales performance, customer contributions, product profitability, and monthly sales patterns.

## Tools and Technologies
- Tableau
- Data Visualization
- Business Analytics
- Calculated Fields
- Groups, Sets, Bins, and Parameters

## Key Features
- Dynamic sales and profitability analysis by product group
- Interactive Top N customer analysis
- Product sub-category sales and profitability analysis
- Sales transaction distribution using adjustable bin sizes
- Monthly sales trends with a dynamic sales threshold

## Key Business Insights
- Technology products generated the highest sales among the three product groups.
- High sales do not always correspond to high profit margins.
- Customer ranking analysis helps identify high-value customers.
- Sales transaction values are heavily right-skewed.
- Sales generally increase toward the end of the year, with November and December showing strong performance.


## Business Applications
This dashboard demonstrates how interactive reporting can support sales performance monitoring, customer analysis, product evaluation, and business decision-making.
